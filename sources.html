Primary sources

These references are first-party help pages and established accessibility guidance. We cite them in individual guides where relevant. Site content was checked on 11 November 2026, but software and support pages can change without advance notice.

Operating systems

Apple publishes Mac shortcut reference material, and Microsoft publishes Windows keyboard commands and configuration help. Application menus remain important when a shortcut depends on focus or a particular program.

Browsers

Google Chrome documents Windows and Mac key combinations. Mozilla documents version-dependent keyboard shortcut customization, which it currently describes as experimental. Verify installed versions before changing a working setup.

Accessibility

W3C WAI explains keyboard operability as an essential web accessibility requirement. WebAIM provides complementary practical testing patterns. These resources inform our keyboard-only navigation guide.
