When one or more keyboard keys stop responding

Separate the key itself from software, layout, connection, and accessibility settings.

By KeyTonic EditorialPublished / checked: 11 Nov 2026Sources linked below

A nonresponsive key is not always a broken mechanical switch. The keyboard may be disconnected, the operating system may be ignoring repeated presses, or a particular application may intercept input. Diagnosis should start with reversible checks that do not risk the device.

Define the failure precisely

Write down which keys fail, when the failure began, and whether it occurs across different applications. Open a harmless plain-text editor and test one key at a time. Avoid testing by repeatedly entering passwords or recovery codes. If one key fails only in one website, look at that website or extension before concluding the keyboard hardware is faulty.

Check connectivity and power

For an external keyboard, inspect the cable or wireless connection. Charge or replace batteries only as directed by the manufacturer. If safe and practical, test a different USB port or pair again using official device instructions. Do not force connectors or open sealed battery compartments. A laptop built-in keyboard needs a different diagnostic path than a detachable Bluetooth keyboard.

Inspect input and accessibility settings

Sticky Keys, Filter Keys, Slow Keys, keyboard layouts, and remapping utilities can change how typing feels. Compare the current settings with the state you expect. Turning off a feature without checking why it was enabled can make the device harder to use for someone relying on accessibility support, so document changes and restore them if they do not help.

Choose a hardware test carefully

If available, test an external keyboard on another trusted device or use a known-good spare on the original computer. A pattern that follows the physical keyboard points toward hardware; a pattern that follows the computer suggests software or configuration. Stop using the keyboard and seek appropriate support if liquid exposure, overheating, or electrical damage is suspected.

Example from a real workflow

Only the letter “E” fails in a browser, but it works in a plain-text editor. That comparison suggests an application or extension issue rather than a broken key. Test the browser without optional extensions before replacing the keyboard.

Try this in order

  1. Record exactly which keys fail and in which apps.
  2. Test in a harmless text editor.
  3. Check cable, wireless connection, and power safely.
  4. Review input layout and accessibility settings.
  5. Compare with a known-good keyboard if available.

Common questions

Should I remove laptop keycaps to test them?

Not as a general first step. Keycap mechanisms are delicate and manufacturer instructions vary.

What if liquid entered the keyboard?

Stop using it and follow manufacturer safety guidance. Do not attempt home electrical repair or apply heat.
